# 火候 · 上部（洁本）

《阴燃》系列的一部长篇。二〇四八年腊月，成都一间茶铺的后屋里，一百二十个人戴着眼镜躺在躺椅上，远程开着美国小城西拉法叶别人出租的身子上夜班；一条新规矩七天后生效，这门隔着海的活计就要停了。上部二十二章，从小年写到除夕夜的零点。

- 全书排印本：[火候_上部_洁本.pdf](火候_上部_洁本.pdf)（A5，257 页，44 幅插图）
- 读前请看：[例言](例言.md)

这是洁本。书里写男女之事的段落，到了那一步就收住，留下前后，不写当中。完整的本子可以向作者索取。
